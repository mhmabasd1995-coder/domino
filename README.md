# Domino AI — بناء التطبيق من الجوال بدون كمبيوتر

## 1) ارفع الملفات على GitHub (من متصفح الجوال)
1. اعمل حساب على github.com، وبعدين: New repository → اكتب أي اسم → Create.
2. داخل المستودع: Add file → Upload files → اختر ملف `project.zip` (لا تفكه) → Commit changes.
3. Add file → Create new file. بخانة الاسم اكتب بالضبط:  `.github/workflows/build.yml`
   والصق داخلها كل محتوى الملف `build.yml` → Commit changes.

## 2) ابنِ الـ APK
1. تبويب Actions → Build APK → Run workflow.
2. انتظر 5-10 دقائق لين تصير علامة صح خضراء.
3. افتح التشغيل → آخر الصفحة Artifacts → domino-apk → تنزل ملف zip، فكه من تطبيق الملفات.
4. ثبّت `app-debug.apk` (اسمح بالتثبيت من مصدر غير معروف).

إذا طلعت علامة حمراء ❌: افتح الخطوة الفاشلة (Build) وانسخ آخر 30 سطر من الخطأ وابعتها لي.

## 3) الاستخدام
1. افتح Domino AI → ابدأ → اسمح بالعرض فوق التطبيقات وبتصوير الشاشة.
2. افتح اللعبة **من أول الجولة** (قبل أي حركة). التطبيق يتتبع كل حركة من تغيّر الأحجار.
3. يظهر شريط صغير تحت شريط الخصم بالحركة المقترحة. أنت تلعبها بإيدك.
4. سكّر لوحة DOMINO AI القديمة قبل ما تبدأ.

## حدود معروفة (نسخة أولى غير مجرّبة على الجهاز)
- مضبوط على لقطات 720×1604. جوالات بتناسب شاشة مختلفة قد تحتاج تعديل بالنسب في Reader.kt.
- لما تتصغّر الطاولة بسلسلة طويلة، نقاط الرقم 6 الرمادية صغيرة وقد ما تنقرأ.
- لو بدأت التطبيق بنص الجولة، ما يعرف الأحجار المنزلة ويطلب منك البدء من أول جولة.
- إذا الحجر يركب على الطرفين بنفس الوقت، يفترض الطرف الأول ويكتب ملاحظة.
